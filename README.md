# Car Price Prediction Using Deep Learning

A deep learning project that predicts car prices using neural networks. This repository implements various deep learning models to estimate car prices based on vehicle features.

## Overview

This project applies deep learning techniques to predict car prices accurately. It leverages neural networks and modern machine learning frameworks to model the relationship between car features and their market prices.

## Features

- **Deep Learning Models**: Implementation of neural networks for regression tasks
- **Data Processing**: Comprehensive data preprocessing and feature engineering
- **Model Evaluation**: Multiple evaluation metrics and error analysis
- **PyTorch Integration**: Built with PyTorch for flexible model development
- **Jupyter Notebooks**: Interactive notebooks for experimentation and visualization

## Project Structure

```
car-price-prediction-deep-learning/
├── data/                      # Dataset directory
├── models/                    # Trained model storage
├── error_analysis/            # Error analysis results and plots
├── requirements.txt           # Project dependencies
└── README.md                  # This file
```

## Tech Stack

- **Python 3.x** - Core programming language
- **PyTorch** - Deep learning framework
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **Scikit-learn** - Machine learning utilities
- **Matplotlib** - Data visualization
- **Jupyter Lab** - Interactive development environment

## Installation

1. Clone the repository:
```bash
git clone https://github.com/goodxarvin/car-price-prediction-deep-learning.git
cd car-price-prediction-deep-learning
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Launch Jupyter Lab to explore the notebooks:
```bash
jupyter lab
```

Run your experiments and models in the interactive notebooks provided.

## Dataset

Place your car price dataset in the `data/` directory. The project expects features and target price values for training and evaluation.

## Model Performance

Results and error analysis are stored in the `error_analysis/` directory, including visualizations and metrics for model evaluation.

## Requirements

Key dependencies include:
- torch (2.9.1) - Deep learning
- pandas (2.3.3) - Data handling
- scikit-learn (1.8.0) - ML utilities
- matplotlib - Visualization
- jupyter lab - Development environment

See `requirements.txt` for the complete dependency list.
